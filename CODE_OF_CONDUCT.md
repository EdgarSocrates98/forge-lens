# Código de Conduta — Contributor Covenant 2.1

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1
como código de conduta. Ao participar, você concorda em manter interações
respeitosas, inclusivas e profissionais.

## Reportar

Problemas de conduta são reportados via GitHub Issues do repositório,
marcando o mantenedor (@EdgarSocrates98). Casos sensíveis podem ser
enviados em privado pelo perfil do mantenedor no GitHub.

Enforcement guidelines seguem o texto canônico do Covenant — sem edição
local que enfraqueça proteções.
