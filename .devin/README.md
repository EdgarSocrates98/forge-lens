# Devin project config — forge-lens

agentic observability — traces, OTLP ingest, evidence-first inspection.

- CLI: `forge-lens` (see AGENTS.md for the operating contract).
- Obsidian export: `forge-lens obsidian status|scan|preview|sync-plan|history` (read verbs pre-allowed in `config.json`; `export`/`export-note` mutate the vault and stay gated).
- `config.json` only declares `permissions` (repo-declarable keys); user-level settings are out of scope.
